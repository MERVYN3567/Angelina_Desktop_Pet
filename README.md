# Angelina 纸飞机桌宠

一款轻量、透明、可自由移动的 Windows 桌面宠物。安洁莉娜会乘着纸飞机在当前屏幕内缓慢飞行，为桌面增添一点陪伴感。

## 功能

- GIF 动画内嵌于 EXE，运行时无需额外素材文件
- 透明无边框窗口，不遮挡桌面
- 动画 2 倍速播放，并使用双缓冲降低闪烁
- 默认开启缓慢自由移动，在屏幕边缘自动折返
- 左键拖动，可手动调整位置
- 右键菜单支持：
  - 放大 / 缩小桌宠
  - 开启 / 关闭自由移动
  - 退出程序
- 单文件 Windows EXE，无需安装 Python 或其他运行环境

## 使用方法

1. 下载 `Angelina纸飞机桌宠-自由移动.exe`
2. 双击运行
3. 左键拖动桌宠；右键打开功能菜单

## 技术实现

- C++ / Win32 API
- GDI+ 播放 GIF 动画
- GIF 资源直接嵌入 EXE
- 透明窗口与置顶显示
- 基于定时器实现动画刷新和自由移动
